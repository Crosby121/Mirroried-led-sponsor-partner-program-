# Sponsor Delivery & Reporting Standard

## Objective
Prove what Mirroried LED actually delivered without inflating performance claims.

## Proof-of-performance record
For each contracted deliverable capture, where applicable:
- deliverable ID;
- activation date;
- location/channel;
- photo, screenshot, content URL, or file reference;
- quantity/count completed;
- start/end dates;
- operator/owner;
- exceptions, downtime, substitutions, or make-goods;
- sponsor approval if required.

## Metric classes
### Class A — Controlled fulfillment
Examples: placement installed, video integration published, event appearance completed, asset displayed for contracted operating period, report delivered.

### Class B — Directly measured response
Examples: tracked QR scans, tracked landing-page clicks, coupon redemptions, form inquiries, attributable campaign codes.

### Class C — Third-party/platform metrics
Examples: YouTube views, social views, engagement, platform analytics. Record source and date captured.

### Class D — Estimates
Clearly label estimates. Never present them as verified results.

## Closeout report structure
1. Sponsor and campaign
2. Campaign objective
3. Contracted deliverables
4. Fulfillment summary
5. Proof gallery/references
6. Available measured results
7. Variances and make-goods
8. Key observations
9. Renewal/recommendation

## Variance handling
If a contracted deliverable cannot be fulfilled as written:
1. Record the issue immediately.
2. Determine the affected quantity/time/value.
3. Notify the sponsor when material.
4. Offer an approved equivalent make-good, extension, credit, or other written remedy.
5. Update the closeout report.

## Reporting rule
Do not omit adverse fulfillment information. Credible reporting protects renewals and the long-term value of the program.
